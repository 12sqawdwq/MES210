# MES210TC Continuous and Discrete Time Signals and Systems Coursework

This repository contains MATLAB solutions for the MES210TC laboratory coursework. The coursework asks for MATLAB code, generated figures, and short observations for continuous-time signals, LTI systems, Fourier analysis, modulation, and pole-zero analysis.

## How to Run

Run all scripts and regenerate every required figure:

```matlab
run('run_all.m')
```

The batch runner disables the tremolo audio playback during automated verification and saves all outputs to `figures/` as both `.png` and `.fig` files. The verification log is saved as `figures/matlab_run_log.txt`.

The formal LaTeX coursework report is available as `MES210_report.tex`, with the compiled PDF at `MES210_report.pdf`.

Verified locally with MATLAB R2024a on 7 June 2026. The local MATLAB installation includes Signal Processing Toolbox but not Control System Toolbox, so scripts that are required by the manual to use `impulse`, `lsim`, or `pzmap` call those functions when available and otherwise use equivalent analytical or numerical fallback methods.

### Experiment 1.2: Basic Signal Operations

Requirements:

- Plot original piecewise signal `f(t)`.
- In the same figure, use subplots for `f(t-2)`, `f(3t)`, `f(-t)`, and `f(-3t-2)`.
- Answer transformation-order questions.

Solution:

- `Q1_2.m` implements the base signal as a piecewise logical expression.
- Each transformation is computed by replacing the argument of `f` with the transformed time variable.
- For `f(-3t-2)`, the inside argument is `-3(t+2/3)`, so it can be understood as a left shift by `2/3`, time reversal, and compression. In general, changing the order of shifting, scaling, and reversal changes the result unless the transformed argument remains algebraically identical.
- `f(3t)` is compressed by a factor of 3, while `f(t/3)` is expanded by a factor of 3.

### Experiment 1.3: Continuous-Time LTI System

Requirements:

- Model `y''(t)+3y'(t)+2y(t)=x'(t)+2x(t)`.
- Determine transfer-function coefficient vectors.
- Plot impulse response with `impulse()`.
- Plot zero-state response to `x(t)=e^(-2t)u(t)` with `lsim()`.

Solution:

- The transfer function is:

```text
H(s) = (s+2)/(s^2+3s+2)
```

- The coefficient vectors are `num=[1 2]` and `den=[1 3 2]`.
- Since `s^2+3s+2=(s+1)(s+2)`, the system reduces to `H(s)=1/(s+1)` after cancellation.
- If Control System Toolbox is installed, `Q1_3.m` uses `tf`, `impulse`, and `lsim`.
- In the verified local environment, the fallback uses `h(t)=e^(-t)u(t)` and `y_zs(t)=e^(-t)-e^(-2t)`.

### Experiment 1.4: Numerical Convolution

### Experiment 2.1: Fourier Series of Rectangular Pulses

Requirements:

- Compute exponential Fourier series coefficients for periodic rectangular pulses with `T=8` and `tau=4,2,1`.
- Use `k=-20:20`.
- Use a `2x2` subplot: time-domain pulses and three magnitude spectra.

Solution:

- `Q2_1.m` computes:

```text
c_k = (tau/T) * sinc(k*tau/T)
```

- Wider pulse width gives a larger DC coefficient and a narrower main lobe.
- Spectral-line spacing is determined by the period `T`, not `tau`, so it does not change across the three cases.
- Narrower time-domain pulses correspond to wider frequency-domain bandwidth.

### Experiment 3.1: RLC Low-Pass Filter

Requirements:

- Model `H(s)=1/(LCs^2+RCs+1)` with `L=0.6 H`, `C=0.2 F`, `R=2 ohm`.
- Use `freqs()` for magnitude and phase response.
- Use `lsim()` to compute zero-state response for `x(t)=sin(t)+sin(20t)`.

Solution:

- `Q3_1.m` uses `freqs(num,den,w)` for the frequency response.
- If Control System Toolbox is available, it uses `lsim`; otherwise it solves the equivalent second-order ODE under zero initial conditions.
- The verified estimate for the `-3 dB` cutoff frequency is approximately `3.40 rad/s`.
- The `20 rad/s` component is attenuated much more than the `1 rad/s` component, confirming low-pass behavior.
- Increasing `R` increases damping, reduces resonance, and generally makes the transition smoother.

### Experiment 3.2: AM Modulation and Demodulation

Requirements:

- Generate baseband `g(t)=4cos(8t)+3cos(16t)`.
- Generate carrier `c(t)=cos(120t)`.
- Generate modulated signal `f(t)=g(t)c(t)`.
- Coherently demodulate with `g0(t)=f(t)c(t)`.
- Apply ideal low-pass filter with `|w|<25`.
- Plot all time-domain signals and spectra.

Solution:

- `Q3_2.m` uses FFT, `fftshift`, ideal frequency-domain masking, `ifftshift`, and `ifft`.
- Modulation shifts baseband components to `120 +/- 8` and `120 +/- 16 rad/s`.
- Multiplying by the carrier again creates baseband terms and high-frequency terms near `240 rad/s`.
- The low-pass filter keeps the baseband terms and removes the high-frequency terms.
- Because `cos^2(120t)=0.5+0.5cos(240t)`, the recovered signal is scaled unless a gain correction is added.
- A supplementary comparison plots `g(t)`, `g_1(t)`, and `2g_1(t)`. The verified MSE decreases from `3.124869` for `g_1(t)` to `0.000310` for `2g_1(t)`, confirming that the recovered waveform shape is correct and mainly needs amplitude restoration.

### Experiment 4.1: Geometric Frequency Response from Poles and Zeros

Requirements:

- Plot poles `-80`, `-120` and double zero at `0`.
- Compute `|H(jw)|` geometrically for `f=0:1:1000 Hz`.
- Verify with `freqs()`.

Solution:

- `Q4_1.m` computes:

```text
|H(jw)| = |jw-z1||jw-z2| / (|jw-p1||jw-p2|)
```

- The double zero at the origin forces low-frequency gain to start near zero.
- As frequency increases, the numerator grows faster at first, so the response rises and approaches high-pass behavior.
- The `freqs()` curve is overlaid with the geometric result for verification.
- A supplementary geometric-distance figure marks one point `jw0` and draws the distance vectors from that point to the double zero and both poles, directly illustrating the magnitude formula.
